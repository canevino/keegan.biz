Purpose

The home page is the main index for the site.

It should feel more like an entry point to a personal archive than a polished portfolio homepage.

Desktop behavior

- rack is fixed to the right
- scarves run vertically
- the homepage scarf is slightly larger
- hover moves a scarf left a little and slightly rotates/scales it
- content leaves enough room on the right so the scarves do not cover the hero text

Mobile behavior

- rack becomes a horizontal strip at the top
- rack can scroll sideways
- scarf hover transforms are removed
- hero content starts below the scarf strip

WIP behavior

Links to pages that are not live should not navigate away.

They open the WIP overlay instead.

The current WIP is intentionally simple:
- crickets start
- horse stays invisible for about 12 seconds
- horse fades in from about 12 to 20 seconds
- horse.gif then continues normally
- closing resets everything

Do not restore the old texture-heavy horse treatment unless intentionally revisiting that project.

Things to preserve

- paper background
- Helvetica
- lowercase/simple type
- scarf navigation
- clean WIP horse
- mobile horizontal scarf behavior
- live links should bypass WIP interception
